# My T 3.32 App Store release notes

Submission status: submitted to Apple on **August 1, 2026** and currently
**Waiting for Review**. This page mirrors the localized release description
submitted to App Store Connect. It does not claim that Apple has approved or
published the version.

## English

My T 3.32 is a comprehensive upgrade:

- A redesigned overview makes vehicle status, battery, range, location, and
  recent activity easier to understand.
- Parking Enhancement presents genuine sleep, wake, lock, door, climate,
  Sentry, plug, unplug, and charging events in chronological order—without
  inventing missing records.
- Drives, parking sessions, and the timeline are newly organized, with search,
  filters, complete route replay, and telemetry analysis.
- Charging analysis now covers grid energy, energy added to the vehicle,
  efficiency, range gained, cost, and charging curves.
- Destination drives can show the genuine trip start, traveled path, road
  route, remaining distance, and ETA.
- Charging and navigation progress can stay current on the Lock Screen and
  Dynamic Island, while vehicle software updates can arrive as notifications.
- Expanded battery, consumption, and regenerative-braking insights use valid
  samples rather than fabricated conclusions.
- The optional My T Companion enhancement remains separate from core features
  and can be enabled or disabled at any time.
- Full support for English, Simplified Chinese, and Traditional Chinese
  (Taiwan).

This release also improves refresh behavior, state synchronization, map
following, animations, stability, and many interface details.

## 简体中文

My T 3.32 是一次全面升级：

- 全新概览，更直观地查看车辆状态、电量、续航、位置与近期活动。
- 停车增强按时间记录休眠、唤醒、门锁、车门、空调、哨兵、插拔充电枪与充电
  变化；只展示真实数据，不补造缺失记录。
- 行程、停车与时间线重新分类，支持搜索、筛选、完整轨迹回放和遥测分析。
- 充电分析新增电网取电、充入车辆、充电效率、续航增量、费用与充电曲线。
- 有目的地行驶可显示真实起点、已行驶轨迹、道路路线、距离和预计到达时间。
- 充电与导航进度可持续更新到锁屏和灵动岛；车辆软件更新可主动通知。
- 电池、能耗与动能回收分析更完整，并坚持仅以有效样本呈现趋势。
- 可选的 My T Companion 扩充服务与基础功能相互独立，可随时开启或关闭。
- 全面支持简体中文、繁體中文（台灣）与 English。

同时改善数据刷新、状态同步、地图跟随、动画、稳定性和大量界面细节。

## 繁體中文

My T 3.32 是一次全面升級：

- 全新概覽，更直覺地查看車輛狀態、電量、續航、位置與近期活動。
- 停車增強依時間記錄休眠、喚醒、門鎖、車門、空調、哨兵、插拔充電槍與充電
  變化；只呈現真實資料，不補造缺失記錄。
- 行程、停車與時間軸重新分類，支援搜尋、篩選、完整軌跡回放與遙測分析。
- 充電分析新增電網取電、充入車輛、充電效率、續航增量、費用與充電曲線。
- 有目的地行駛可顯示真實起點、已行駛軌跡、道路路線、距離與預計抵達時間。
- 充電與導航進度可持續更新至鎖定畫面與動態島；車輛軟體更新可主動推播。
- 電池、能耗與動能回收分析更完整，並堅持只以有效樣本呈現趨勢。
- 選用的 My T Companion 擴充服務與基本功能彼此獨立，可隨時開啟或關閉。
- 全面支援簡體中文、繁體中文（台灣）與 English。

同時改善資料更新、狀態同步、地圖跟隨、動畫、穩定性與大量介面細節。
